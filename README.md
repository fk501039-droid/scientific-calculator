# Scientific Calculator

A beginner-friendly command-line scientific calculator written in Python.

## Features

- Addition, subtraction, multiplication, division, and powers
- Square root
- Sine, cosine, and tangent (angles in degrees)
- Common logarithm (`log10`) and natural logarithm (`ln`)
- Basic input and calculation error handling

## Requirements

- Python 3.8 or newer
- No third-party packages required

## Run

1. Install Python from https://www.python.org/downloads/ if it is not already installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   ```bash
   python main.py
   ```

   On some systems, use `python3 main.py`.

## Example

```text
=== Scientific Calculator ===
Operations: +  -  *  /  **  sqrt  sin  cos  tan  log  ln
Angles for sin/cos/tan are entered in degrees.
Type 'q' to quit.

Operation: +
First number: 12
Second number: 8
Result: 20
```
